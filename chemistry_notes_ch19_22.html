第19章 化学反应和能量

19.1 化学反应中的热量变化

化学反应在生成新物质的同时，总是伴随着能量的变化。能量变化通常表现为热量的释放或吸收，也可转化为电能、光能等。

1. 放热反应与吸热反应

  • 放热反应：凡是有热量放出的化学反应。如炭/氢气燃烧、酸碱中和、铝热反应。
  • 吸热反应：凡是吸收热量的化学反应。如高温煅烧石灰石、Ba(OH)2·8H2O 与 NH4Cl 反应。

2. 微观本质与键能

断开化学键需要吸收能量，形成化学键则会放出能量。

  • 键能 (Bond Energy)：拆开 1 mol 气态物质中某种共价键所需要吸收的能量。键能越大，共价键越牢固，分子越稳定。
微观计算公式：
反应热 ΔH = 反应物总键能（断键吸收总能量） - 生成物总键能（成键释放总能量）
以 H2(g) + Cl2(g) → 2HCl(g) 为例：ΔH = (436.4 + 242.7) - (2 × 431.8) = -184.5 kJ/mol（放热反应）。

3. 宏观能量与能量守恒定律

19.2 反应热、焓变与热化学方程式

  • 反应热 (Heat of Reaction)：在化学反应过程中，当反应物和生成物具有相同温度时释放或吸收的热量。
  • 焓 (H) 与 焓变 (ΔH)：在恒温、恒压条件下，体系仅做体积功时吸收或释放的热量称为焓变，单位为 kJ/mol 或 kJ·mol⁻¹。

2. 黑斯定律 (Hess's Law)

一个化学反应，不论是一步完成还是分几步完成，其总的热效应是完全相同的。反应的焓变 ΔH 仅与起始状态和最终状态有关，与反应途径无关。

思考题 19f 黑斯定律计算生成热

已知 CH4(g)、C(s,石墨)、H2(g) 的燃烧热分别为 -890.3 kJ/mol、-393.5 kJ/mol、-285.8 kJ/mol，求 C(s,石墨) + 2H2(g) → CH4(g) 的反应热 ΔH。

正确答案：ΔH = -74.8 kJ/mol
目标方程 = ②(C燃烧) + 2×③(H₂燃烧) - ①(CH₄燃烧)
ΔH = (-393.5) + 2×(-285.8) - (-890.3) = -74.8 kJ/mol。

第21章 化学平衡的移动

21.1 可逆反应与动态平衡

化学平衡状态：正反应速率等于逆反应速率 (R正 = R逆 > 0)，各组分浓度保持恒定。

21.2 影响化学平衡移动的因素与勒沙特列原理

勒沙特列原理：如果改变影响平衡的一个因素（浓度、压强或温度），平衡将向着削弱这种外来影响的方向移动。

22.2 溶度积与溶解度的换算关系

对于难溶电解质 AmBn(s) ⇌ m An+(aq) + n Bm-(aq)：

溶度积表达式： Ksp = [An+]m · [Bm-]n
不同类型难溶物换算： AB 型中 s = √K_{sp}；AB₂ 型中 s = ∛(K_{sp} / 4)。

22.3 溶度积规则与沉淀转化

溶度积规则：Qsp < Ksp 沉淀溶解；Qsp > Ksp 析出沉淀。
